# Knowledge Base & Playbooks

This directory contains defensive security playbooks in Markdown format used by CyberSage AI's RAG pipeline.

Playbooks provide curated, deterministic guidance on incident triage, IOC verification, containment, and eradication for threats such as:
- Credential stuffing & SSH brute-force
- Phishing & suspicious email headers
- Endpoint malware persistence
- Cloud IAM credential leaks & privilege escalation
